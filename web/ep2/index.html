The Mandelbrot Set is a Map of Chaos

Part 1 lived on a line. Here is the whole plane: every point of the Mandelbrot set is a rule $z\mapsto z^2+c$, and every rule has its own world, a Julia set. Click anywhere on the set to visit it.

1Squaring in the plane

A complex number is a point of the plane, or an arrow with a length $|z|$ and an angle $\arg z$. Multiplying complex numbers multiplies lengths and adds angles, so $z^2$ has the length squared and twice the angle. Drag the orange arrow: inside the unit circle $z^2$ moves closer to 0, outside it flies away. The rule of this page is $f_c(z) = z^2 + c$: stretch-and-turn, then shift by $c$.

2Where does 0 go?

Two planes side by side. Left: the parameter $c$, i.e. which rule we use. Right: the plane where the orbit $z_0 = 0,\ z_1 = c,\ z_2 = c^2 + c,\ \ldots$ lives. Click or drag on the left to choose $c$. Once an orbit leaves the disk of radius 2 (blue) it never comes back, since $|z|>2,\ |z|\ge|c| \Rightarrow |z^2+c| \ge |z|(|z|-1) > |z|$. The Mandelbrot set is

$$M = \{\, c \in \mathbb{C} : \text{the orbit of } 0 \text{ stays bounded} \,\}.$$

Scroll to zoom (single precision: down to about 10⁻⁵), double-click to reset.

3The cardioid is a stability test

In the central region the orbit of 0 settles on a fixed point $z^\ast = z^{\ast 2}+c$. Exactly as in Part 1, chapter 2, it is stable when $|f_c'(z^\ast)| = |2z^\ast| < 1$. On the boundary $2z^\ast = e^{i\theta}$, hence $$c = z^\ast - z^{\ast 2} = \tfrac12 e^{i\theta} - \tfrac14 e^{2i\theta},$$ a cardioid. At $\theta=\pi$, $c=-\tfrac34$: Part 1's first doubling $r_1 = 3$. The 2-cycle $z_1z_2$ has $z_1z_2 = c+1$, multiplier $4(c+1)$, hence the disk $|c+1|<\tfrac14$. Move $c$ along (or inside) the cardioid with the sliders below and watch the orbit in the widget above.

4Bulbs, rotations and fractions

The bulb attached to the cardioid at $\tfrac pq$ of a turn holds an attracting cycle of period $q$, which rotates around the fixed point by $\tfrac pq$ of a turn at each step (checked numerically for all $q\le 13$). Its antenna has $q$ spokes, and its size is close to $\sin(\pi p/q)/q^2$. Jump to any bulb:

Between two bulbs, the largest one is given by the Farey sum $\tfrac ab \oplus \tfrac cd = \tfrac{a+c}{b+d}$. Iterating it from $\tfrac12, \tfrac13$ gives $\tfrac25, \tfrac38, \tfrac5{13},\ldots$ — Fibonacci periods — converging to the golden angle $1/\varphi^2$.

6Julia sets: one world per point

Fix $c$ and colour every starting point $z_0$ by the same rule: cream if its orbit stays bounded. The cream set is the filled Julia set $K_c$. Click or drag on the Mandelbrot set (left) and the Julia set (right) follows. The white dots are the orbit of the critical point 0.

$c \in M \iff K_c$ is connected (Fatou, Julia, 1919). The reason is the critical point 0, the only point where $f_c'(z) = 2z$ vanishes — the analogue of $x=\tfrac12$ in Part 1: if its orbit escapes, the Julia set shatters into dust. In the mosaic, the connected Julia sets draw the Mandelbrot set itself: $M$ is an index of all the Julia sets. Near points like $c = i$, $M$ even looks like the Julia set it indexes (Tan Lei, 1990).
